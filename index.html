Project highlights

git fame

Summarise and pretty-print who wrote what in a git repository. 950+ stars, 100k+ gem downloads.

git ai

Leave the commit message empty and a git hook writes it from the staged diff. Rust, 50k+ downloads on crates.io.

Re:map

An expressive data transformation DSL for Ruby 3 built on refinements and pattern matching. 110k+ downloads.

rfix

RuboCop that only lints and auto-fixes the lines you actually committed. 80k+ downloads.

Home Assistant MCP

A Model Context Protocol server that lets an LLM query and control your smart home. Published on npm.

mcp-env-keychain

Keep API keys in the macOS Keychain and hand them to AI agents without ever showing them: Touch ID gated, output redacted.

More MCP servers

Read-only MariaDB, Logz.io log search and a GitHub Actions runner on top of nektos/act, all speaking MCP.

u701

A Rust BLE proxy on an ESP32-C3 that makes the Carpe Iter Terrain Command handlebar controller work with iOS.

Upstream work merged into dry-rb (dry-core, dry-logic, dry-types), dip, esp32-nimble, overcommit, Anycomplete, atom/language-ruby and vscode-atom-keybindings, among others.
